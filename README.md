# 🌍 Global Data Science Jobs Salary Analytics Dashboard

# 📖 Project Overview

This project presents an interactive **Power BI Dashboard** built to analyze **Global Data Science Jobs Salaries** across different countries, experience levels, company sizes, employment types, and remote work ratios.

The dashboard transforms raw salary data into meaningful business insights through interactive KPI cards, charts, and slicers, enabling users to explore salary trends efficiently.

---

# 📂 Dataset Information

- 📄 Dataset Name: Global Data Science Jobs Salary Dataset
- 📁 File Format: Excel (.xlsx)
- 🌍 Countries Covered: 73
- 💼 Job Titles: 118
- 💵 Salary Currency: USD
- 📅 Years Covered: 2020–2023

# 📌 KPI Cards

The dashboard includes the following KPI Cards:

- 🌍 Total Countries
- 💰 Average Salary
- 👨‍💼 Employee Count
- 📉 Minimum Salary
- 📈 Maximum Salary
- 💼 Total Job Titles

---

# 📊 Charts & Visualizations

The dashboard contains multiple interactive charts:

- 📈 Average Salary by Job Title
- 📊 Employee Count by Experience Level
- 🍩 Employee Count by Remote Ratio
- 🥧 Employee Count by Company Size
- 📉 Average Salary by Work Year
- 🌳 Employee Count by Company Size (Treemap)

---

# 🎛️ Interactive Slicers

Users can dynamically filter the dashboard using:

- 📅 Work Year
- 👨‍💼 Experience Level
- 🏢 Company Size
- 📄 Employment Type

---

# 📈 Key Insights

✔ Executive-level professionals receive the highest salaries.

✔ Medium-sized companies employ the highest number of professionals.

✔ Average salaries increased from 2020 to 2023.

✔ Remote work has become increasingly common within Data Science roles.

✔ Salary trends vary significantly across different experience levels.
